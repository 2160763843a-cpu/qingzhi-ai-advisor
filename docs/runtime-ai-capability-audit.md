# 官方运行时 AI 能力审计报告

- 审计日期：2026-10-01
- 审计范围：COSMO Code 平台文档与当前开发/发布运行环境
- 结论分类依据：区分「COSMO Code 用于开发代码」与「发布后的应用能否调用官方模型」

## 1. COSMO Code（开发侧）

- 竞赛项目代码由 COSMO Code 平台 AI Agent 辅助开发，平台 AI 仅在开发阶段使用。
- 该能力属于开发工具链，随应用发布后不存在、不可打包、不可复用，与运行时能力无关。

## 2. 发布应用的运行时 AI 能力

对当前运行环境逐项核查的结果：

| 核查项 | 结果 |
| --- | --- |
| 官方提供的、允许发布应用调用的模型 SDK / 接口 | 未发现。平台未提供面向参赛应用运行时的模型调用接口或 SDK 文档 |
| 是否需要密钥、额度或额外开通 | 不适用（无可接入的官方运行时接口，平台 AI 亦明确禁止提取任何 API Key） |
| 正式发布环境是否可调用 | 不可调用。应用以静态前端构建产物 + Node.js 静态服务方式发布，无任何模型推理端点 |
| 竞赛规则是否明确允许该运行时能力 | 未见任何允许发布应用接入官方模型运行的条款；同时规则明确禁止外部 API 与第三方模型 |

## 3. 结论

当前应用无法具备通用大模型推理能力，只能通过混合NLU增强自由表达泛化。

应用实际采用的是「本地混合NLU引擎」：文本规范化 + 同义归一 + 字符2/3-gram + TF-IDF 加权 kNN 统计分类 + 高精度确定性业务短语规则 + 对话状态特征 + Top1/Top2 差距判断与低置信度澄清。该方案为纯本地实现，不调用任何外部模型或第三方 API，商品、价格与 FAQ 答案全部来自结构化数据（data/*.json），分类器不生成任何事实内容。

说明页与文档中对该能力的表述统一为「本地混合NLU引擎」，不使用「LLM 推理」等描述。

## 4. 后续条件

若未来平台明确提供官方运行时模型接口、发布环境可调用且竞赛规则允许，将先输出接口、限制与验证证据，经用户确认后再评估是否接入；本版本不接入。
