## 四、五维评分

1. **创意度 20%（预估 17-18）**：可解释推荐（硬约束+分项评分+最接近方案）、合规留资（授权状态机+脱敏）、三类记录统一 Store、真实事件驱动看板贯穿青岛本地场景；扣分点：UI 形态仍偏标准客服对话。证据：/chat、/compare、/leads、/dashboard。
2. **完整度 25%（预估 22-24）**：咨询→识别→推荐→对比→线索→运营分析全链路联动，售后/投诉/安全/拒绝分支闭环，空态/无匹配/刷新恢复/重置入口齐备；扣分点：双标签页同步、运营看板导出图表为轻量条形图。全部 8 路由 200。
3. **场景价值 25%（预估 22-23）**：解决"只回答不沉淀"——意向评分、漏斗、品类热度解释运营价值；全程模拟数据声明，无虚构业绩；扣分点：缺少真实企业对接叙事（竞赛口径不允许）。
4. **设计打磨 10%（预估 8-8.5）**：四视口无横向溢出、页头自适应、语义化表格/焦点样式；扣分点：视觉统一打磨留待下一轮（按用户要求本轮不动）。
5. **COSMO Code 使用深度 20%（预估 18-19）**：20+ 轮增量开发、先失败后修复流程、25 个自动化测试脚本（累计 1500+ 断言）、Git 提交历史完整。**明确表述：COSMO Code 用于项目规划、编码、测试和调试；发布应用运行时采用本地混合 NLU、可解释规则和结构化数据（docs/runtime-ai-capability-audit.md）。** 待截取证据清单：多轮需求对话、失败测试先行运行输出、测试通过输出、git log、看板/对比页运行截图。
